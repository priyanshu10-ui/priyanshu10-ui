## 🚀 Featured Project

### 🌾 Krishi Sahayak – AI-Based Farmer Support System

An AI-powered agricultural platform designed to empower farmers with accessible, intelligent and multilingual farming assistance.

**Key Features:**
- 🤖 AI-powered farming assistant.
- 🌱 Crop health detection using computer vision.
- 🌦️ Weather forecasting and farming advisories.
- 📊 Live agricultural market and Mandi prices.
- 🏛️ Government schemes and subsidy information.
- 🎙️ Multilingual voice assistance.
- 🌍 Regional language accessibility.

**Tech Focus:** AI, Web Development, Firebase, APIs, NLP and Multilingual Processing.

🔗 **Live Project:** [Visit Krishi Sahayak](https://krishak-chi.vercel.app/)
